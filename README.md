# Gerenciador de Produtos

Sistema academico para gerenciamento de produtos, desenvolvido como atividade de TecWeb.

## Stack planejada

- Frontend: React, Vite, JavaScript, React Router DOM, Context API e CSS externo.
- Backend: Node.js, Express, CORS e API REST.
- Persistencia: arquivo JSON local.
- Ferramentas: npm, Git, GitHub e GitHub Projects/Kanban.

## Observacao

O projeto tera frontend em React e backend em Express, organizados em pastas separadas.
